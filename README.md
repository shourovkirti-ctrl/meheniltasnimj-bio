## 🚀 দ্রুত শুরু করুন (Local Setup)

১. টার্মিনাল ওপেন করে প্রজেক্ট ফোল্ডারে যান:
   ```bash
   cd c:\Antygravity\Linktree
   ```

২. ডেভেলপমেন্ট সার্ভার চালু করুন:
   ```bash
   npm run dev
   ```

৩. ব্রাউজারে ওপেন করুন: [http://localhost:3000](http://localhost:3000)

## 🛠️ কিভাবে আপনার লিঙ্ক ও তথ্য পরিবর্তন করবেন?

সবকিছু পরিবর্তন করার জন্য আপনাকে শুধুমাত্র একটি ফাইল এডিট করতে হবে:
📂 **[`src/config/profile.ts`](./src/config/profile.ts)**

এই ফাইলটিতে সহজ বাংলায় সবকিছু বুঝিয়ে দেওয়া আছে:
- **নাম ও হ্যান্ডেল:** `name: "আপনার নাম"`, `handle: "@username"`
- **প্রোফাইল ছবি:** `avatar: "ছবির URL"` (অথবা আপনার ছবি `public/` ফোল্ডারে রেখে `"/my-photo.jpg"` দিতে পারেন)
- **সোশ্যাল মিডিয়া:** Facebook, Instagram, YouTube, X, WhatsApp, LinkedIn ইত্যাদি
- **লিঙ্কসমূহ:** আপনার ওয়েবসাইট, পোর্টফোলিও, ইউটিউব ভিডিও, মিটিং বুকিং ইত্যাদি
- **স্ট্যাটাস ব্যাজ:** আপনি কি নতুন প্রজেক্টের জন্য উন্মুক্ত কিনা
- **কন্টাক্ট কার্ড (vCard):** আপনার মোবাইল নাম্বার ও ইমেইল (যাতে ভিজিটররা এক ক্লিকে ফোনে সেভ করতে পারে)

## 🌐 কিভাবে অনলাইনে ফ্রিতে হোস্ট করবেন? (Vercel-এ ২ মিনিটে ডেপ্লয়)

সবচেয়ে সহজ এবং সবচেয়ে দ্রুত উপায় হলো **Vercel** (এটি ১০০% ফ্রি):

### ধাপ ১: গিটহাবে পুশ করুন (GitHub Repository)
1. [GitHub.com](https://github.com)-এ একটি নতুন রিপোজিটরি তৈরি করুন (যেমন `my-linktree`)।
2. নিচের কমান্ডগুলো টার্মিনালে রান করুন:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of my bio linktree"
   git branch -M main
   git remote add origin https://github.com/your-username/my-linktree.git
   git push -u origin main
   ```

### ধাপ ২: Vercel-এ ডেপ্লয় করুন
1. [Vercel.com](https://vercel.com)-এ ফ্রি একাউন্ট তৈরি করুন বা GitHub দিয়ে লগইন করুন।
2. **"Add New Project"** এ ক্লিক করে আপনার GitHub রিপোজিটরি সিলেক্ট করুন।
3. **"Deploy"** বাটনে ক্লিক করুন।
4. মাত্র ৬০ সেকেন্ডের মধ্যে আপনার ওয়েবসাইট লাইভ হয়ে যাবে এবং আপনি একটি ফ্রি লিঙ্ক পাবেন (যেমন: `yourname.vercel.app`)!

## 🏷️ কাস্টম ডোমেইন যুক্ত করার নিয়ম

যদি আপনার নিজস্ব ডোমেইন থাকে (যেমন `yourname.com` বা `links.yourdomain.com`):
1. Vercel ড্যাশবোর্ডে গিয়ে আপনার প্রজেক্টের **Settings > Domains**-এ যান।
2. আপনার ডোমেইন বা সাব-ডোমেইন লিখুন (যেমন: `links.yourdomain.com`)।
3. Vercel যে CNAME রেকর্ড দেখাবে, তা আপনার ডোমেইন প্রোভাইডার (Cloudflare, Namecheap ইত্যাদি)-এর DNS-এ যোগ করে দিন।
4. সাথে সাথে সম্পূর্ণ ফ্রিতে SSL সার্টিফিকেট সহ কাস্টম ডোমেইন চালু হয়ে যাবে!
